YouTube Live Tweet 手順書

OBS で配信開始を押すと、告知ツイートの下書きが自動で開きます。ポストを押すだけ。

手順1: ダウンロード

youtube_live_tweet.lua を、好きな場所(ドキュメントフォルダなど)に保存します。

手順2: OBS で選ぶ

OBS のメニューから「ツール」→「スクリプト」を開き、左下の「＋」ボタンを押して、保存した youtube_live_tweet.lua を選びます。

※画面はイメージです。実際の表示とは異なる場合があります。

手順3: チャンネル URL を入れる

追加すると右側に設定欄が出ます。「YouTube チャンネルの URL」に、自分のチャンネルページの URL をそのまま貼ります(例 https://www.youtube.com/@xxxx)。

※画面はイメージです。実際の表示とは異なる場合があります。

他の項目はそのままで OK です。

投稿文は好みで変えてよいです({title} の部分に配信タイトルが入ります)。

ヒント: チャンネル URL の調べ方
YouTube で自分のアイコンをクリックし、「チャンネルを表示」を選びます。表示されたページのアドレスバーの URL をコピーして、上の欄に貼ります。

これで完了。使い方

配信開始を押す → しばらくすると投稿画面が開く → 内容を確認して「ポストする」を押す。

※画面はイメージです。実際の表示とは異なる場合があります。

先に試したいときは「テスト: 今すぐ投稿画面を開く」を押します(配信中でないとタイトルは空で開きます)。

うまくいかないとき

症状対処
何も開かない URL が違うかもしれません。設定欄の一番下のステータス表示を確認し、「スクリプトログ」ボタンでログを見てください。
X のログイン画面が出る ブラウザで X にログインしてください。
タイトルが空で開く YouTube 側の反映が遅いだけです。手で入力してください。「最大待ち時間」を増やすと解決する場合があります。
同じ配信でもう一度開きたい 「テスト: 今すぐ投稿画面を開く」ボタンを押してください。
ゲームが最小化された ゲームをボーダーレスウィンドウにするか、配信開始直後の待機画面の間にポストしてください。
OBS を入れ直したら消えた 手順2からやり直してください。

解決しないときは配布ページ(GitHub の Issues)で、OBS のバージョンとスクリプトログの内容を添えて報告してください。

注意
最後の「ポストする」は自分で押します(自動では投稿されません)。
