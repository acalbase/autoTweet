# alternatives/

OBS Lua 版(`../lua/`)の前に作った代替実装です。

- **`powershell/`** — WebSocket 経由で OBS に常駐接続する PowerShell 版。手順書は `docs/manual-powershell.html`。
- **`python/`** — 最初に作った実装。手順書は `docs/manual-python.html`(詳細は `python/README.md` も参照)。

いずれもメンテナンス対象外の参考実装です。通常は OBS Lua 版(`../lua/youtube_live_tweet.lua`)を使ってください。
